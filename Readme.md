# Access DB

* Enter data by opening the TimeLines.accdb  .
* Use the navigation buttons at the very bottom of the screen to find your study
or create a new study at the end.
* Each row in the Timelines Box must have the first three columns completed.
* Use the tab button to get to the next column.
* Use the drop down button to select, rather than typing.


The data is sent to the visualisation app by exporting to a file "timelines.xml".
This should be created automatically on closing the access DB.  But you need to give permission

# Access DB Permissions

* File> options > Trust Centre >Trust Center Settings > trusted locations> Add New Location

* Tick Subfolders of this location are laso trusted > OK

# Visualisation App


* Direct your browser to [](https://cam-ctu.github.io/timelines/)
* Select the file in this directory "timelines.xml"
